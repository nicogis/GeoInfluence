# GeoInfluence screenshots

Store release screenshots in this folder.

Recommended files:

```text
01-ribbon-light.png
02-ribbon-dark.png
03-dockpane-input.png
04-allocation-preview.png
05-confidence-preview.png
06-regions-output.png
07-raster-output.png
```

## Capture guidelines

- use a representative point dataset;
- keep ArcGIS Pro UI readable;
- avoid sensitive project paths or customer data;
- use the same dataset for preview, regions and raster screenshots when possible;
- crop only enough to keep the GeoInfluence workflow and map context visible;
- capture at least one light-theme and one dark-theme ribbon image.

After screenshots are added, the main README can embed the most representative two or three images.
